# Project Summary: Vehicle Rental System

| Item | Details |
|---|---|
| Title | Vehicle Rental System |
| Problem | Manual rental records cause double booking, delays and calculation errors |
| Objective | Web system to manage vehicles, customers, rentals, returns and payments |
| Target users | Administrator, Staff, Customer |
| Core modules | Vehicles, Customers, Rentals, Returns, Payments |
| Scope | Web app with CRUD, search, reports. No mobile app, payment gateway or GPS tracking |

## Functional Requirements
User login, manage vehicles, manage customers, check availability, create rentals, calculate rent, process returns and late fees, record payments, search and filter, reports.

## Non-Functional Requirements
Security, performance, reliability, usability, scalability, maintainability.
